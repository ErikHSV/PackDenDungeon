# 🃏 Pack Legends

Ein eigenständiges Browser-Kartenspiel: Öffne Booster-Packs, sammle Helden, stelle ein Team zusammen und kämpfe dich durch immer schwierigere Stufen.

## Spielen
`index.html` im Browser öffnen – kein Build nötig. (Oder per GitHub Pages hosten.)

## Features
- **4 Pack-Typen**: Gratis (alle 5 Min.), Abenteurer, Champion (Selten+ garantiert), Mythen (Episch+ garantiert)
- **26 Helden** in 4 Raritäten, 5 Rollen (Wächter, Klinge, Schütze, Magier, Heiler) und 5 Elementen
- **Duplikate** leveln Helden auf (bis Stufe 10)
- **Auto-Kampf** mit Element-Vorteilen, Kritischen Treffern, Flächenzaubern und Heilung
- **Bosskampf** auf jeder 5. Stufe
- Spielstand wird automatisch im Browser gespeichert
